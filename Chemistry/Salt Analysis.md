For **CBSE Class 12 salt analysis**, the best approach is to follow a fixed **deduction flowchart** rather than randomly performing tests.

# 1. Start with Preliminary Examination

Observe the given salt:

### **Colour**

This can immediately give clues:

- **Blue** → possibly $\mathrm{Cu^{2+}}$
    
- **Light green** → possibly $\mathrm{Fe^{2+}}$
    
- **Yellow/brown** → possibly $\mathrm{Fe^{3+}}$
    
- **Pink** → possibly $\mathrm{Co^{2+}}$ or $\mathrm{Mn^{2+}}$
    
- **White/colourless** → many common ions like $\mathrm{NH_4^+,Zn^{2+},Al^{3+},Ca^{2+},Ba^{2+}}$
    

⚠️ Colour is only a **clue**, not confirmation.

---

# 2. Test Solubility in Water

Take a small amount and add water.

Ask:

- Does it dissolve completely?
    
- Is the solution coloured?
    
- Is it insoluble?
    

This helps decide which tests are practical.

---

# 3. First Identify the **Anion**

Usually, do **dilute acid tests first**.

## Step A: Add dilute $\mathrm{HCl}$ or dilute $\mathrm{H_2SO_4}$

Observe whether a gas is evolved.

### If gas evolves:

|Observation|Possible anion|
|---|---|
|Colourless gas turns limewater milky|$\mathrm{CO_3^{2-}}$|
|Rotten egg smell|$\mathrm{S^{2-}}$|
|Pungent choking gas, decolourises $\mathrm{KMnO_4}$|$\mathrm{SO_3^{2-}}$|
|Brown fumes|$\mathrm{NO_2^-}$|

### Carbonate:

CO32−+2H+→CO2+H2O\mathrm{CO_3^{2-}+2H^+\rightarrow CO_2+H_2O}

Then confirm $\mathrm{CO_2}$ using limewater:  
Ca(OH)2+CO2→CaCO3↓+H2O\mathrm{Ca(OH)_2+CO_2\rightarrow CaCO_3\downarrow+H_2O}

---

# 4. If No Gas → Test for Halides / Sulphate

Take a **fresh solution**.

## Add dilute $\mathrm{HNO_3}$ followed by $\mathrm{AgNO_3}$

|Precipitate|Anion|
|---|---|
|White|$\mathrm{Cl^-}$|
|Pale yellow|$\mathrm{Br^-}$|
|Yellow|$\mathrm{I^-}$|

Confirm with $\mathrm{NH_4OH}$ if required.

---

## Test for Sulphate $\mathrm{SO_4^{2-}}$

Acidify with dilute $\mathrm{HCl}$, then add $\mathrm{BaCl_2}$.

**White precipitate insoluble in HCl**:

SO42− confirmed\boxed{\mathrm{SO_4^{2-}\ confirmed}}

Ba2++SO42−→BaSO4↓\mathrm{Ba^{2+}+SO_4^{2-}\rightarrow BaSO_4\downarrow}

---

## Test for Nitrate $\mathrm{NO_3^-}$

Perform the **brown ring test**:

Add freshly prepared $\mathrm{FeSO_4}$ solution, then carefully add concentrated $\mathrm{H_2SO_4}$ along the side.

A **brown ring** indicates:

NO3−\boxed{\mathrm{NO_3^-}}

---

# 5. Now Identify the **Cation**

The easiest logical order is:

## First test $\mathrm{NH_4^+}$

Add $\mathrm{NaOH}$ and warm gently.

If ammonia is evolved:

- pungent smell
    
- turns moist red litmus blue
    

Then:

NH4+\boxed{\mathrm{NH_4^+}}

NH4++OH−→NH3+H2O\mathrm{NH_4^++OH^-\rightarrow NH_3+H_2O}

---

# 6. Perform the Group Analysis

For the common CBSE salts, this sequence is useful:

### Add $\mathrm{NaOH}$ solution

Observe precipitate and behaviour in excess $\mathrm{NaOH}$.

|Observation|Possible cation|
|---|---|
|White ppt soluble in excess|$\mathrm{Zn^{2+}}$ or $\mathrm{Al^{3+}}$|
|Blue ppt|$\mathrm{Cu^{2+}}$|
|Green ppt turning brown|$\mathrm{Fe^{2+}}$|
|Reddish-brown ppt|$\mathrm{Fe^{3+}}$|
|White ppt insoluble in excess|$\mathrm{Ca^{2+}}$, etc.|

---

# 7. Confirm Using $\mathrm{NH_4OH}$

This is extremely useful.

### $\mathrm{Cu^{2+}}$

Light blue ppt initially, which dissolves in excess $\mathrm{NH_4OH}$ to give a **deep blue solution**.

Cu2+ confirmed\boxed{\mathrm{Cu^{2+}\ confirmed}}

### $\mathrm{Zn^{2+}}$

White ppt dissolves in excess $\mathrm{NH_4OH}$.

### $\mathrm{Fe^{2+}}$

Dirty green precipitate.

### $\mathrm{Fe^{3+}}$

Reddish-brown precipitate.

### $\mathrm{Al^{3+}}$

White ppt with $\mathrm{NaOH}$, soluble in excess $\mathrm{NaOH}$ but generally **not soluble in excess $\mathrm{NH_4OH}$**.

This distinguishes it from $\mathrm{Zn^{2+}}$.

---

# The Best Overall Decision Order 🧪

Use this in the practical:

### **STEP 1 — Observe**

Colour + appearance + solubility.

⬇️

### **STEP 2 — Test for $\mathrm{NH_4^+}$**

Salt + $\mathrm{NaOH}$ + heat.

⬇️

### **STEP 3 — Test anion using dilute acid**

Gas?

- $\mathrm{CO_3^{2-}}$
    
- $\mathrm{S^{2-}}$
    
- $\mathrm{SO_3^{2-}}$
    

⬇️

### **STEP 4 — If no gas**

Use:

- $\mathrm{AgNO_3}$ → $\mathrm{Cl^-,Br^-,I^-}$
    
- $\mathrm{BaCl_2}$ → $\mathrm{SO_4^{2-}}$
    
- Brown ring → $\mathrm{NO_3^-}$
    

⬇️

### **STEP 5 — Identify cation**

Use:

- $\mathrm{NaOH}$
    
- excess $\mathrm{NaOH}$
    
- $\mathrm{NH_4OH}$
    
- specific confirmatory test
    

⬇️

### **STEP 6 — Combine them**

For example:

- Anion confirmed: $\mathrm{SO_4^{2-}}$
    
- Cation confirmed: $\mathrm{Cu^{2+}}$
    

Therefore:

CuSO4\boxed{\mathrm{CuSO_4}}

---

## My biggest tip for practical exams

Don't write **“therefore salt is X”** immediately from one observation.

Always structure it as:

> **Observation → Inference → Confirmatory test → Final inference**

For example:

> White precipitate with $\mathrm{BaCl_2}$ which remains insoluble in dilute $\mathrm{HCl}$ confirms the presence of $\mathrm{SO_4^{2-}}$.

Then do the same independently for the cation, and **only then combine them to deduce the salt**.
